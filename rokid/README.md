# Stark для Rokid AI Glasses

Нативное Android-приложение (без Unity) для лёгких очков **Rokid AI Glasses / Rokid Glasses**
(49 г, камера, монохромный зелёный экран, YodaOS-Sprite на базе Android). Читает тот же пакет `.stark`,
что и Unity-плеер для XREAL, и тот же протокол Studio → очки по Wi‑Fi.

## Чем отличается от плеера для XREAL

| | XREAL Air 2 Ultra + Beam Pro | Rokid AI Glasses |
|---|---|---|
| Модель на столе (6DoF) | да | **нет**: у очков нет пространственного трекинга |
| Жесты рукой | да | **нет**: управление сенсором на дужке |
| 3D | цветная модель на столе | зелёная 3D-схема перед глазами, детали шага подсвечены и «прилетают» |
| Текст шага, крепёж, инструмент, проверки | да | да, крупно |
| Пакет из Studio по QR | камера Beam Pro → ссылка | камера очков сканирует QR сама |

## Экран

* Сверху: «Шаг 3 из 8 · изделие» и подсказка шага (до 80 символов).
* В середине: 3D-схема. Собранное тускло, детали текущего шага ярко с анимацией установки и видны
  сквозь корпус, будущие детали скрыты. Схема медленно покачивается, чтобы был виден объём.
* Снизу: детали (`•`), крепёж с количеством и моментом затяжки (`+ Болт M6 ×4 · 9,5 Н·м`), инструмент,
  проверки, `! Проверить` для шагов, которые инженер не подтвердил. Последняя строка: связь со Studio.
* Чёрный цвет на волноводе прозрачен, поэтому фон чёрный, всё остальное зелёное разной яркости.

## Управление

| Действие | Что делает |
|---|---|
| Свайп вперёд (или вниз) по дужке | следующий шаг |
| Свайп назад (или вверх) | предыдущий шаг |
| Короткое касание | повторить анимацию установки |
| Долгое касание (0,65 с) | меню |
| «Назад» два раза | выход |

Если на ваших очках свайп работает наоборот, в меню есть «Свайп: обычный / обратный».
Клавиши тоже работают (стрелки, Enter, Menu), поэтому приложение можно проверять на телефоне или в эмуляторе.

Меню: сканировать QR из Studio, открыть другой пакет, начать сборку сначала, выключить 3D-схему
(крупный текст, меньше расход батареи), направление свайпа, отключить Studio.

## Установка на очки

1. В приложении **Hi Rokid** на телефоне: раздел «Разработчик» → включить отладку (ADB).
2. Подключить очки к компьютеру **кабелем для разработчика** (штатный кабель из коробки только заряжает).
3. Установить APK:
   ```
   adb install -r stark-rokid-0.1.N.apk
   adb shell am start -n app.stark.rokid/.MainActivity
   ```
   Сразу после установки открывается встроенный образец «Редукторный модуль».

Все сборки подписаны одним тестовым ключом (`app/stark-test.keystore`), поэтому новая версия ставится
поверх старой без удаления. Для заказчиков нужен отдельный ключ, которого нет в git.

## Как попадает пакет

* **По Wi‑Fi из Studio.** Включите Wi‑Fi на очках (по умолчанию он выключен ради батареи), в Studio нажмите
  «QR», на очках: меню → «Сканировать QR из Studio» и посмотрите на QR-код на мониторе. Дальше кнопка
  «На очки» в Studio доставляет каждую новую версию сама (опрос раз в 3 с, проверка SHA-256).
  Без сканирования: `adb shell am start -a android.intent.action.VIEW -d "'stark://link?u=http%3A%2F%2F<IP>%3A8041&t=<токен>'"`.
* **Кабелем.** `adb push изделие.stark /sdcard/Android/data/app.stark.rokid/files/` — приложение откроет его само
  в течение 3 секунд.
* Номер шага запоминается для каждого изделия, при новой версии из Studio шаг сохраняется.

## Сборка

APK собирает GitHub Actions (`.github/workflows/rokid-apk.yml`): тесты ядра, `assembleDebug`, затем запуск
на эмуляторе Android 12 с экраном 480×640 и скриншоты каждого экрана (артефакт `rokid-screenshots`).
Готовый APK — артефакт `stark-rokid-apk`.

Локально нужен Android SDK 34 и JDK 17: `cd rokid && ./gradlew :app:assembleDebug`.

```
app/src/main/java/app/stark/rokid/
  core/            без Android, покрыто тестами: StarkPackage (.stark), GlbModel (model.glb), StudioLink,
                   StepHud (тексты шага, анимация), TouchGesture (жесты дужки)
  MainActivity     экран, ввод, меню, загрузка пакетов
  ModelRenderer    3D-схема на OpenGL ES 2.0
  LinkClient       опрос Studio по Wi‑Fi
  QrScanActivity   QR-код камерой очков (zxing)
  PackageStore     где лежат пакеты, последний шаг, сопряжение со Studio
```

## Не проверено на реальных очках

* Какие события отдаёт сенсор дужки на вашей прошивке (обрабатываются и клавиши, и касания, и touchpad).
* Разрешение и плотность экрана: размеры шрифтов считаются от ширины экрана.
* Доступ сторонних приложений к камере (её может держать встроенный ассистент).
