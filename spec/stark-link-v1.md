# Stark Link v1: Studio → очки по Wi‑Fi

Как пакет `.stark` попадает из Stark Studio в Stark Player без кабеля и `adb`.

## Принцип

* Редактор Studio слушает только `127.0.0.1:8040` (CAD заказчика не уходит в сеть).
* Для очков Studio по запросу поднимает **отдельный** сервер на `0.0.0.0:8041`. Он отдаёт ровно один файл:
  пакет, который инженер отправил кнопкой «На очки». CAD, проекты и API редактора через него недоступны.
* Доступ по секретному токену (`secrets.token_urlsafe(18)`, 24 символа `[A-Za-z0-9_-]`), который передаётся
  только через QR-код. «Новый QR» в Studio меняет токен: старые очки теряют доступ.
* Плеер **сам опрашивает** Studio (pull). Studio не знает адресов очков и ничего им не шлёт.

## Сопряжение

1. Studio показывает QR-код со ссылкой `http://<IP компьютера>:8041/s/<token>`.
2. Камера Beam Pro (или телефона) открывает её в браузере: страница с кнопкой
   «Открыть в Stark Player» = `stark://link?u=<base url, URL-encoded>&t=<token>`.
3. Android запускает плеер (intent-filter `VIEW stark://link`, добавляется при сборке
   `StarkAndroidBuild`). Плеер сохраняет `u` и `t` в PlayerPrefs.

Плеер также принимает сам адрес страницы `http://<ip>:8041/s/<token>` (ручной ввод, редактор Unity).
Ссылки с путём в `u`, не-http схемами или коротким токеном отклоняются.

## API (порт 8041)

Токен: заголовок `X-Stark-Token: <token>` (или `?t=<token>`). Имя устройства: `X-Stark-Device` (необязательно,
показывается в Studio).

| Запрос | Ответ |
|---|---|
| `GET /api/v1/ping` | `{"app":"stark-studio","protocol":1}`, без токена |
| `GET /api/v1/current` | `{"app","protocol":1,"package": null \| {id, name, version, sha256, size, steps, sentAt}}` |
| `GET /api/v1/current.stark` | байты пакета; `ETag: "<sha256>"`, `X-Stark-Version`, `X-Stark-Sha256`; `304` при `If-None-Match` |
| `GET /s/<token>` | HTML-страница сопряжения |

Ошибки: `403 {"error":"bad_token"}`, `404 {"error":"no_package"}`.
`version` растёт на 1 при каждой отправке, `sha256` = SHA-256 файла `.stark`.

## Поведение плеера

* Опрос `current` каждые 3 с; при ошибках сети пауза растёт до 30 с; при возврате в приложение сразу.
* Новая версия = `sha256` отличается от загруженного пакета. Плеер скачивает файл, проверяет SHA-256,
  сохраняет в `persistentDataPath/Packages/<id>.stark` (доступен без сети) и открывает.
* Если модель уже стоит на столе, она остаётся на месте с тем же поворотом, масштабом и номером шага.
* Пакет, который не прошёл проверку формата, отклоняется до выгрузки текущей модели.
* `protocol` больше 1 → сообщение «обновите Stark Player».

## Ограничения v1

* Без TLS: рассчитано на доверенную локальную сеть. Токен защищает от случайных устройств в сети, не от
  перехвата трафика. Для заводских сетей позже: HTTPS с самоподписанным сертификатом и отпечатком в QR.
* Если у компьютера сменился IP (DHCP), QR-код нужно отсканировать заново.
* В Docker контейнер не знает IP компьютера: задайте `STARK_LINK_ADVERTISE=192.168.x.x`.
