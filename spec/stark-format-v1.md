# Формат пакета `.stark` v1

Контракт между Stark Studio (ПК) и Stark Player (очки). Плеер ничего не знает про CAD,
Studio ничего не знает про очки. Любое изменение формата = новая `formatVersion`.

## Состав (zip)

```
project.stark
├── manifest.json        версия формата, изделие, языки, статистика
├── model.glb            упрощённая цветная модель, каждый узел = деталь, имя узла = partId
├── steps.json           детали и шаги сборки
├── hints/ru.json        подсказки: { hintKey: "текст ≤ 80 символов" }
├── hints/kk.json        (если заполнены)
├── hints/en.json        (если заполнены)
└── media/               зарезервировано: фото, видео, иконки инструмента
```

## Координаты

* `model.glb`: стандарт glTF, **метры, ось Y вверх**. Сборка стоит на плоскости y = 0, центр по X/Z в 0.
* Узел детали несёт полную матрицу своей итоговой позиции. Одинаковые детали (болты) делят одну сетку.
* Пути установки (`insertPath`, `partPaths`) заданы **смещениями в метрах в системе сцены glTF**
  относительно итоговой позиции детали. Последняя точка всегда `[0, 0, 0]`.
  Плеер анимирует деталь от `path[0]` до `path[last]` (цикл ~2 с).

## steps.json

```json
{
  "formatVersion": 1,
  "parts": [
    { "id": "P006", "name": "Крышка корпуса", "qty": 1, "tags": [] },
    { "id": "P008", "name": "Болт M6x58 DIN 912:1", "qty": 1, "tags": ["fastener"] }
  ],
  "steps": [
    {
      "id": "S07",
      "title": "Установить: Крышка корпуса, закрепить Болт M6x58 DIN 912 ×4",
      "parts": ["P006"],
      "fasteners": [
        { "partIds": ["P008", "P009", "P010", "P011"], "name": "Болт M6x58 DIN 912",
          "qty": 4, "torqueNm": 9.5,
          "partPaths": { "P008": [[0, 0.06, 0], [0, 0, 0]] } }
      ],
      "insertPath": [[0, 0.04, 0], [0, 0, 0]],
      "partPaths": { "P006": [[0, 0.04, 0], [0, 0, 0]] },
      "tool": "Шестигранник 5 мм",
      "hintKey": "H007",
      "checks": ["Прокладка уложена в паз"],
      "camera": { "focus": "P006", "explode": 0.0 },
      "review": null
    }
  ]
}
```

| Поле | Смысл |
|---|---|
| `parts` (в шаге) | Основные детали шага: подсвечиваются голубым и «прилетают» по своему пути |
| `fasteners` | Крепёж шага: подсвечивается оранжевым с количеством `×N`; `torqueNm` может быть `null` |
| `insertPath` | Путь первой детали шага (для простых плееров) |
| `partPaths` | Путь каждой детали шага; `null`, если планировщик не нашёл путь |
| `hintKey` | Ключ в `hints/<lang>.json`. Постоянный: не меняется при перестановке шагов |
| `checks` | Пункты самопроверки сборщика |
| `review` | Не `null`, если планировщик просит инженера проверить шаг (интерференция, не вынимается по прямой) |

Порядок шагов в массиве = порядок сборки. Каждая деталь встречается ровно в одном шаге
(в `parts` или в `fasteners[].partIds`), это проверяет валидатор Studio перед экспортом.

## Валидация при экспорте (Studio)

Ошибки (экспорт запрещён): нет узла glTF для детали; деталь в двух шагах; неизвестная деталь;
шаг без деталей; шаг без подсказки `ru`.
Предупреждения: подсказка длиннее 80 символов; деталь без шага; шаг «требует проверки»;
больше 200 тыс. треугольников.

## Отличия от черновика в архитектуре

* `fasteners[].partId` заменён на `partIds` (список экземпляров), чтобы плеер подсвечивал каждый болт.
* Добавлены `title`, `partPaths`, `review`.
* `hintKey` не совпадает с `id` шага, чтобы подсказки не терялись при перестановке.
